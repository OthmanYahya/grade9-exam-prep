# PyLevel K — Grade 9 Python Revision & Practice

A dedicated, editorial-style revision and interactive practice application for Grade 9 students studying introductory Python (Chapter 3: Level K).

Built with **React 18**, **TypeScript**, **Vite**, and **Vitest**.

---

## Features

1. **Curriculum Study Guide (8 Sections)**
   - Section 1: What the exam is most likely to test
   - Section 2: Core Concepts & IDLE (Editor vs Shell)
   - Section 3: Variables, naming rules, types, and guided tracing
   - Section 4: `print()`, quotation marks, `sep=`, and `end=`
   - Section 5: `input()` and `int()` — the classic string-concatenation exam trap
   - Section 6: Operators (`+`, `-`, `*`, `/`, `%`, `**`, `+=`, `==`, `!=`, `<`, `>`, `<=`, `>=`, `and`, `or`, `not`)
   - Section 7: 6-step method for solving "What is the output?" questions
   - Section 8: Exam traps worth memorizing & accuracy notes
   - Interactive 9-skill Last-Minute Exam Checklist
   - Mastery Targets for Levels 1–4

2. **Complete 48-Question Practice Engine**
   - **Level 1 (Q1–12):** Build confidence (definitions, IDLE, valid variable names, basic operators)
   - **Level 2 (Q13–26):** Regular exam practice (traces, assignment updates, case sensitivity, print separators, remainder `%`, integer input)
   - **Level 3 (Q27–38):** Predicted harder combinations (multi-step traces, exact output with `sep`/`end`, negative numbers, order of operations)
   - **Level 4 (Q39–48):** Surprises, debugging, code repair, and short programs
   - Support for single-choice, multiple-choice (e.g. Q5, Q11, Q46), exact output (Q32, Q33), and code repair/writing (Q39–45)
   - Immediate feedback in **Practice Mode** with step-by-step variable tracing and official worked explanations
   - Delayed grading in **Exam Mode** simulating a real exam setting
   - Non-spoiling guided hints on every question

3. **In-Session Variable Tracing Scratchpad**
   - Unobtrusive scratchpad accessible at any time via button or keyboard shortcut (`S`)
   - Pre-formatted variable tracing template
   - Persists notes automatically in local storage

4. **Results & Error Remediation**
   - Clear accuracy score distinguishing auto-graded and self-assessed exercises
   - Tier-by-tier breakdown (Level 1, Level 2, Level 3, Level 4)
   - Filter by all, mistakes, or correct answers
   - One-click **Retry Missed Questions** button

5. **Local Progress & Persistence**
   - Tracks questions attempted, mastered, and needing practice
   - Tracks completed revision sections and checklist items
   - Logs recent sessions
   - Safe one-click Reset Progress option

---

## Running Locally

```bash
# Install dependencies
npm install

# Run automated test suite
npm run test

# Build for production
npm run build

# Preview production build
npm run preview
```
